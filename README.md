# NØRTH — Architecture Studio Concept Website

NØRTH is an **Independent Concept Project** designed and developed by SEEKBLACK to demonstrate a complete brand website experience for an architecture and spatial design studio.

## Live Demo

https://north.seekblack.cn/

## Case Study

https://seekblack.cn/work/north/

## Product goal

The demo is intentionally presented as a complete standalone studio website rather than a portfolio screenshot. Visitors can browse projects, project details, studio information, journal entries and contact content as they would on a real production site.

## Main sections

- Home
- Work / Projects
- Project Detail
- Studio
- Journal
- Journal Detail
- Contact
- 404

## Design direction

- Editorial architecture aesthetic
- Olive / neutral visual system
- Large-format typography
- Project-led information architecture
- Responsive desktop and mobile layouts

## Stack

- Semantic HTML
- CSS
- Vanilla JavaScript
- Static multi-page architecture

## Concept project disclosure

NØRTH is not presented as a real client commission. It is an independent concept experience created to demonstrate product structure, visual direction, responsive implementation and production-level front-end delivery.

Source code is published for portfolio review. No open-source license is granted unless explicitly stated otherwise.
